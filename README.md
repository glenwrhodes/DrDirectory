# DrDirectory

A fast, fully featured disk-usage analyzer for Windows in the spirit of WinDirStat / WizTree / TreeSize,
written in C++20 with Qt 6.

## Features

- **Fast multithreaded scanning** of one or more drives or any folder (Win32 `FindFirstFileEx` with large
  fetch, long-path aware, junctions/symlinks are never followed so nothing is double-counted). Live progress,
  determinate for whole drives, cancellable with Esc.
- **Directory tree** with Name, % of parent (bar), Size, Items, Files, Folders, Last Modified (newest in
  subtree) and Attributes. Sort by any column; multi-select.
- **Cushion-shaded squarified treemap** (SequoiaView/WinDirStat style) coloured by file type:
  click to select, double-click or mouse wheel to drill into a folder, Backspace / wheel-down / mouse back
  button to zoom out, breadcrumb bar to jump to any level, hover tooltips, folder labels, optional grid
  and flat shading.
- **File Types** pane: size, share and count per extension with Windows type names; select one to outline
  every file of that type in the treemap.
- **Largest Files** pane: top 2,000 files with instant filter.
- **Cleanup**: Delete to Recycle Bin (Del) or permanently (Shift+Del) for any multi-selection, with
  confirmation; the tree, totals, treemap and statistics update in place without rescanning.
- **<Unknown>** (used space the scan could not see) and optional **<Free Space>** items on drives.
- Refresh just one folder (F5) or everything (Ctrl+F5); Show in Explorer, Open, Open Terminal Here,
  Copy Path, Windows Properties dialog; Export any subtree to CSV.
- Restart as Administrator to measure protected folders; drag & drop folders onto the window;
  command line `DrDirectory.exe C:\ D:\Projects`; remembers layout and options.

## Building

Requires Visual Studio 2022 (Desktop C++) and Qt 6.5+ for MSVC 2022 64-bit.

```bat
build.bat
```

`build.bat` defaults to `C:\Qt\6.10.2\msvc2022_64` (override with `set QTDIR=...`), configures with the
CMake and Ninja that ship with Qt, builds Release into `build\` and runs `windeployqt`, so
`build\DrDirectory.exe` runs standalone.

The application icon is generated by `tools/make_icon.py` (pure Python, no dependencies).

## Keyboard

| Key | Action |
| --- | --- |
| Ctrl+O | Scan drive or folder |
| F5 / Ctrl+F5 | Refresh selected folder / rescan all |
| Esc | Stop scan |
| Del / Shift+Del | Recycle / delete permanently |
| Ctrl+E | Show in Explorer |
| Ctrl+C | Copy path |
| Alt+Enter | Properties |
| Ctrl+Z | Zoom treemap to the selected folder |
| Ctrl+- / Ctrl++ / Ctrl+0 | Zoom out / in / reset |
| F9 | Toggle treemap |
